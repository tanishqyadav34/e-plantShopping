# Paradise Nursery

Paradise Nursery is a responsive plant shop experience for discovering indoor plants and managing a shopping cart.

## Tech stack

- Vite
- React (JavaScript)
- Redux Toolkit and React Redux
- Plain CSS

## Features

- Welcoming landing page with an introduction to Paradise Nursery
- Eighteen plants across air-purifying, aromatic, and succulent categories
- Add-to-cart feedback and live cart quantity badge
- Quantity controls, item removal, subtotals, and total amount
- Responsive layout for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
